# Vrushti Lakhupota: UI/UX Portfolio

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Add your CV (do this before deploying)
Put your CV at `assets/Vrushti-Lakhupota-CV.pdf`. The Download CV button already points there.

## Deploy
1. Create a GitHub repo and push this folder (repo root = this folder).
2. On vercel.com choose Add New > Project, import the repo, leave Framework Preset as "Other", and deploy.

## Edit content
All project text lives in the `PROJECTS` array at the top of `script.js`. Case study images are in `assets/cases/`.
